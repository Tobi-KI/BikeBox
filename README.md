# BikeBox Tauschbörse

Einfache statische Website für Radreisende, um Fahrradkartons (Bikeboxen) anzubieten oder Gesuche zu veröffentlichen.

## Funktionen

- Angebote und Gesuche erfassen
- Darstellung in einer Liste
- Visualisierung auf einer Karte (OpenStreetMap via Leaflet)
- Sprachumschaltung Deutsch / Englisch

## Lokal starten

```bash
npm start
```

Die App läuft dann auf `http://localhost:8000`.

Alternativ geht weiterhin:

```bash
python3 -m http.server 8000
```
